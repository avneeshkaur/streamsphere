Full-stack video streaming platform with user authentication and content management.

## ✨ Features
- 🔐 User authentication (JWT)
- 🎬 Video content management
- 📱 Responsive UI
- 🗄️ MongoDB data persistence

## 🛠️ Tech Stack
Node.js · Express.js · MongoDB · Mongoose · React · JWT · bcrypt

## 🚀 Getting Started
```bash
git clone https://github.com/avneeshkaur/streamsphere
cd streamsphere
npm install
npm start
```
